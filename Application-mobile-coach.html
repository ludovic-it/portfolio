Coach IMG – Version 1

Première version de l'application mobile qui calcule l'IMG

Changements de la Version 1

V1 est la base du projet : calcul IMG, interface XAML, affichage d'un message et d'un smiley. C'est la version de référence avant les améliorations V2, V3, V4 et V5.

Cette première étape m'a surtout permis de valider la logique métier (formule IMG), la saisie utilisateur et le rendu visuel du résultat sur mobile.

En pratique, la V1 répond au besoin principal du projet : prendre des données simples (poids, taille, âge, sexe), calculer l'IMG et afficher une interprétation claire. Même si la version reste simple, elle fixe toutes les bases techniques utilisées ensuite.

Formule de Deurenberg (détaillée)

Le calcul de l'IMG repose sur la formule de Deurenberg. C'est une formule reconnue qui combine l'IMC, l'âge et le sexe pour estimer le pourcentage de masse grasse. 

IMG = (1.2 × IMC) + (0.23 × âge) - (10.8 × sexe) - 5.4

avec :
- IMC = poids (kg) / taille² (m)
- sexe = 1 pour un homme, 0 pour une femme

Pour la V1, cette formule est le cœur métier : l'application convertit d'abord la taille en mètres, calcule l'IMC, puis applique la formule complète. Le résultat final est affiché en pourcentage.

Lecture simple des paramètres

  • Poids : plus le poids augmente (à taille égale), plus l'IMG monte.
  • Taille : elle agit via l'IMC, donc elle influence fortement le résultat.
  • Âge : le terme 0.23 × âge fait progresser l'IMG avec l'âge.
  • Sexe : le coefficient change le résultat selon homme/femme.

Exemple oral rapide

Exemple : pour 70 kg, 1,75 m, 28 ans, homme. On calcule d'abord l'IMC (environ 22,86), puis on applique la formule. On obtient un IMG d'environ 18,4 %, qui est ensuite interprété par l'application avec un message et un visuel.

Extraits de code (implémentation V1)

Voici comment la formule est matérialisée en C# dans le modèle métier :

public void CalculIMG()
{
    double tailleEnMetres = taille / 100.0;
    double sexeValue = sexe ? 1.0 : 0.0;
    img = (1.2 * poids / (tailleEnMetres * tailleEnMetres))
          + (0.23 * age)
          - (10.8 * sexeValue)
          - 5.4;
}

Interprétation du résultat selon des seuils différents homme/femme :

private void ResultatIMG()
{
    if (sexe == 0) // femme
    {
        if (img < 25.0) message = "maigre";
        else if (img <= 30.0) message = "Parfait";
        else message = "Surpoids";
    }
    else if (sexe == 1) // homme
    {
        if (img < 15.0) message = "Trop maigre.";
        else if (img <= 20.0) message = "Parfait.";
        else message = "Surpoids.";
    }
}

Extrait du clic sur « Calculer IMG » dans la page (création du profil, affichage, smiley) :

Profil unProfil = new Profil(sexe, poids, taille, age);
LblResultat.Text =
    $"Votre IMG est de {unProfil.Img:F2} %.\n{unProfil.Message}";
// mise à jour de l’image selon le message...

Fichiers principaux dans la solution : interface XAML (MainPage.xaml), code-behind (MainPage.xaml.cs), modèle avec calcul (Profil.cs), bootstrap MAUI (MauiProgram.cs).

Ce que la V1 apporte concrètement

Calcul IMG

Implémentation de la formule de Deurenberg avec affichage du pourcentage.

Interface MAUI

Formulaire simple avec poids, taille, âge et sexe.

Retour visuel

Message et smiley selon l'interprétation du résultat.

Personnalisation homme/femme

La formule et les seuils d'interprétation s'adaptent au sexe sélectionné.

Gestion d'erreur de saisie

Un message alerte l'utilisateur si une valeur est invalide.

Base de code réutilisable

La logique de calcul est isolée pour faciliter les évolutions futures.

Cible multi-plateforme

Le projet MAUI prépare déjà Android, iOS, macOS et Windows.

Détail fonctionnel (niveau oral BTS)

  • L'utilisateur saisit ses données dans trois champs numériques.
  • Le sexe est choisi via boutons radio, avec un choix exclusif.
  • Le bouton de calcul déclenche la création d'un profil et le calcul IMG.
  • Le résultat affiche un pourcentage + un message métier.
  • Un smiley renforce la lecture rapide du résultat.
  • En cas d'erreur de saisie, une alerte protège l'expérience utilisateur.

Pourquoi cette V1 est importante

Sans cette version, les améliorations suivantes n'auraient pas de base solide. La V1 valide la logique métier, le parcours utilisateur et la structure globale de l'application. Les versions V2 à V5 viennent ensuite améliorer la persistance, l'organisation du code, la navigation et la documentation.
