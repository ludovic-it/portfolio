Site de Gestion du Personnel

Application web PHP pour gérer des employés, avec organisation MVC

Démonstration

Présentation du projet

Dans le cadre de mon BTS SIO option SLAM, j'ai créé un site de gestion du personnel en PHP. Le projet suit le modèle MVC pour séparer les pages, la logique et les données.

Les données sont stockées en MySQL et l'interface est responsive avec Bootstrap. Les mots de passe sont protégés avec un hash sécurisé.

1. Page d'accueil (index.php)

La page d'accueil sert de point d'entrée à l'application et redirige automatiquement l'utilisateur vers la page de connexion. 

case "login":
default:
    require_once "controleurs/C_login.php";
    $controleur = new C_login();
    $controleur->action_afficher();
    break;

2. Système d'authentification

2.1 Page de connexion (login.php)

L'utilisateur arrive sur cette page et dispose de deux options : se connecter avec des identifiants existants ou s'inscrire pour créer un nouveau compte.

2.2 Inscription

Lors de l'inscription, les informations sont enregistrées en base et le mot de passe est stocké de manière sécurisée.

2.3 Page d'accueil utilisateur

Après connexion, l'utilisateur arrive sur un écran qui permet d'accéder à la liste des employés et de consulter les données dans un tableau.

3. Fonctionnalités principales

3.1 Ajout d'employés

Un formulaire permet d'ajouter un nouvel employé simplement.

3.2 Déconnexion

Un bouton de déconnexion est accessible depuis l'interface principale, permettant une gestion sécurisée de la session utilisateur.

4. Interface utilisateur

4.1 Site responsive

Bootstrap est utilisé pour une interface lisible sur ordinateur et mobile.

4.2 Éléments d'interface

L'interface comprend une barre de navigation principale avec menu responsive, des boutons au design cohérent avec Bootstrap, et des tableaux pour une présentation claire des données employés.

5. Base de données et sécurité

5.1 Sécurité des données

Les mots de passe sont hachés avec SHA-256 et salage pour garantir la sécurité des données utilisateurs.

6. Technologies utilisées

PHP MVC MySQL Bootstrap phpMyAdmin SHA-256

7. Conclusion

Ce projet montre la mise en place d'un site de gestion complet : connexion, affichage des employés, ajout via formulaire et sécurisation des accès.

Il m'a permis de consolider mes bases en PHP, MVC, MySQL et sécurité web pour un niveau BTS.
