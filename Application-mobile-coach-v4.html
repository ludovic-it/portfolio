Coach IMG - Version 4

Menu de navigation et écran historique séparé

Nouveautés de la Version 4

La V4 améliore surtout l'expérience utilisateur : l'application devient plus simple à utiliser au quotidien grâce à une navigation claire.

Au lieu d'avoir tout sur un seul écran, la V4 sépare les usages en pages dédiées, tout en gardant la base SQLite introduite en V3.

Cette version est particulièrement intéressante en démonstration orale car le parcours est plus lisible : on comprend mieux chaque étape.

Menu principal

Une page d'accueil permet d'aller directement vers le calcul IMG ou l'historique.

Écran historique séparé

L'historique n'est plus mélangé avec le formulaire de calcul, la lecture est plus claire.

Navigation multi-pages

Le parcours est mieux structuré, ce qui rend l'application plus compréhensible en démonstration.

Continuité SQLite

La persistance locale de la V3 est conservée, avec la même logique de stockage.

Extraits de code (navigation)

Passage de la page menu ou d'accueil vers le calcul ou l'historique avec la pile de navigation MAUI :

await Navigation.PushAsync(new CalculPage());
await Navigation.PushAsync(new HistoriquePage());

Retour à la page précédente après consultation de l'historique :

await Navigation.PopAsync();

Exemple de gestionnaire associé à un bouton du menu (pattern classique code-behind) :

private async void OnAllerHistoriqueClicked(object sender, EventArgs e)
{
    await Navigation.PushAsync(new HistoriquePage());
}
