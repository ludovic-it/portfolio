Coach IMG - Version 3

Ajout de SQLite et historique des mesures

Nouveautés de la Version 3

La V3 marque une vraie étape : on passe d'une simple sauvegarde JSON à une base SQLite qui permet de suivre plusieurs mesures dans le temps.

Concrètement, l'application ne garde plus uniquement le dernier calcul : elle enregistre un historique exploitable, avec un affichage plus utile pour l'utilisateur.

Pour l'oral, c'est une version clé car elle montre un passage vers un vrai stockage structuré, plus proche d'une application professionnelle.

Base SQLite

Les profils sont stockés dans une base locale structurée et plus fiable.

Date de mesure

Chaque calcul est horodaté, ce qui permet de comparer l'évolution de l'IMG.

Historique complet

La V3 permet de récupérer plusieurs entrées et pas seulement la plus récente.

Requêtes asynchrones

La lecture/écriture en base se fait en async pour éviter de bloquer l'interface.

Extraits de code (SQLite)

Création de la connexion et de la table au premier accès :

connection = new SQLiteAsyncConnection(DatabasePath, Flags);
await connection.CreateTableAsync<Profil>();

Insertion d'une nouvelle mesure après calcul (profil avec date et identifiant auto) :

DateTimeOffset date = DateTimeOffset.Now;
Profil unProfil = new Profil(null, date, sexe, poids, taille, age);
await SQLiteDbCoach.SaveItemAsync(unProfil);

Lecture de tout l'historique pour l'affichage (tri par id ou date selon la requête utilisée) :

var liste = await connection.QueryAsync<Profil>(
    "SELECT * FROM Profil ORDER BY id DESC");
