Chatbot Openbiz Dev

Assistant virtuel interactif développé en JavaScript

Présentation du projet

J'ai développé un chatbot pour Openbiz Dev afin d'aider les visiteurs à trouver le bon service et à prendre rendez-vous plus facilement.

Le chatbot pose des questions simples, enregistre les réponses et propose la suite la plus adaptée selon le besoin et la localisation.

Fonctionnalités principales

La conversation suit un parcours clair : choix du service, quelques questions de besoin, choix du pays, puis proposition d'un rendez-vous via Calendly.

Les catégories de services

📚 Étude

Audit digital, Stratégie marketing, Analyse de marché, Conseil en transformation digitale

🌐 Site

Site vitrine, E-commerce, Application web, Refonte de site, Maintenance

📱 Social

Gestion réseaux sociaux, Community management, Publicité sociale, Influence marketing, Création de contenu

Le flux de conversation

Le chatbot guide l'utilisateur à travers un parcours structuré :

  1. Message de bienvenue : Présentation et explication du processus
  2. Sélection de catégorie : Choix parmi Étude, Site ou Social
  3. Sélection de sous-service : Affichage des options selon la catégorie
  4. Qualification : Questions sur l'objectif, site existant, budget et délai
  5. Localisation : Choix du pays (France, Côte d'Ivoire, Autre)
  6. Cas clients : Proposition d'exemples pertinents (optionnel)
  7. Résumé : Affichage de toutes les informations collectées
  8. Action finale : Redirection vers Calendly ou contact par email

Organisation du projet

Le projet est développé sans framework, avec un code organisé par fonctions : messages, étapes de conversation et événements utilisateur.

Structure des fichiers

Le projet est organisé en trois fichiers principaux :

  • index.html : Structure HTML avec la page de démonstration et le conteneur du chatbot
  • chatbot1.js : Logique JavaScript complète du chatbot (gestion d'état, conversation, événements)
  • styles.css : Styles CSS avec variables CSS, animations, et design responsive

Gestion des messages

Le système de messages permet d'afficher les messages du bot et de l'utilisateur avec des animations fluides. Chaque message peut contenir des boutons d'options pour guider l'utilisateur dans sa navigation. 

function ajouterMessageBot(texte, options = null) {
    const messageDiv = document.createElement('div');
    messageDiv.className = 'message bot';
    
    const contentDiv = document.createElement('div');
    contentDiv.className = 'message-content';
    contentDiv.textContent = texte;
    
    messageDiv.appendChild(contentDiv);
    
    if (options && options.length > 0) {
        const optionsDiv = document.createElement('div');
        optionsDiv.className = 'message-options';
        
        options.forEach(option => {
            const btn = document.createElement('button');
            btn.className = 'option-btn';
            btn.textContent = option.text;
            btn.onclick = () => option.action();
            optionsDiv.appendChild(btn);
        });
        
        messageDiv.appendChild(optionsDiv);
    }
    
    chatbotMessages.appendChild(messageDiv);
    // Scroll automatique avec animation
    setTimeout(() => {
        chatbotMessages.scrollTo({
            top: chatbotMessages.scrollHeight,
            behavior: 'smooth'
        });
    }, 50);
}

Initialisation

Une fonction vérifie que les éléments HTML existent avant d'activer le chatbot, pour éviter les erreurs et les doubles démarrages. 

function initialiserChatbot() {
    // Prévenir les doubles initialisations
    if (chatbotContainer && chatbotContainer.dataset.initialized === 'true') {
        return;
    }
    
    // Récupérer les éléments DOM
    chatbotContainer = document.getElementById('chatbotContainer');
    chatbotToggle = document.getElementById('chatbotToggle');
    // ... autres éléments
    
    // Vérifier que tous les éléments existent
    if (!chatbotContainer || !chatbotToggle || ...) {
        console.error('Erreur : Tous les éléments ne sont pas présents');
        return;
    }
    
    // Attacher les événements
    chatbotToggle.addEventListener('click', ...);
    
    // Marquer comme initialisé
    chatbotContainer.dataset.initialized = 'true';
}

Développement

Design et animations

Le design utilise un thème sombre avec des accents bleus. Les animations CSS rendent l'interface plus agréable sans compliquer l'usage.

Les effets visuels incluent : dégradés animés, effets glassmorphism, animations de brillance (shimmer), effets de pulsation, transformations 3D subtiles, et ombres multicouches pour créer de la profondeur.

Gestion des événements

Les clics sont gérés avec addEventListener. J'ai aussi sécurisé les interactions pour éviter que certains effets visuels bloquent les actions utilisateur. 

chatbotToggle.addEventListener('click', (e) => {
    e.preventDefault();
    e.stopPropagation();
    if (chatbotContainer.classList.contains('active')) {
        fermerChatbot();
    } else {
        ouvrirChatbot();
    }
}, { capture: true });

function afficherTyping() {
    const typingDiv = document.createElement('div');
    typingDiv.className = 'typing-indicator';
    typingDiv.id = 'typingIndicator';
    
    for (let i = 0; i < 3; i++) {
        const dot = document.createElement('div');
        dot.className = 'typing-dot';
        typingDiv.appendChild(dot);
    }
    
    chatbotMessages.appendChild(typingDiv);

Responsive Design

Le chatbot est entièrement responsive et s'adapte aux différentes tailles d'écran. Sur mobile, le chatbot occupe presque toute la hauteur de l'écran pour une meilleure expérience utilisateur.

Outils utilisés

Le projet repose sur JavaScript, HTML et CSS, sans framework lourd. Le chargement est rapide et le code reste lisible.

Les fonctionnalités modernes utilisées incluent : les variables CSS pour la cohérence des couleurs, les animations CSS avec keyframes, les transitions avec cubic-bezier, les pseudo-éléments pour les effets visuels, et les media queries pour le responsive design.

JavaScript (ES6+)

Langage de programmation principal, utilisant les fonctionnalités modernes comme async/await, les fonctions fléchées, et la manipulation du DOM.

HTML5

Structure sémantique moderne avec éléments HTML5 pour une meilleure accessibilité et référencement.

CSS3

Styles avancés avec variables CSS, animations, transitions, et design responsive avec media queries.

Calendly

Intégration de l'API Calendly pour permettre la prise de rendez-vous directement depuis le chatbot.
