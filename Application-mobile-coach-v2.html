Coach IMG – Version 2

Version 2 avec sauvegarde des données et code mieux organisé

Nouveautés de la Version 2

Cette V2 améliore la V1 sur deux points importants : les données sont maintenant sauvegardées, et le projet est mieux structuré.

L'utilisateur retrouve ses informations au redémarrage, ce qui rend l'application plus pratique. Côté code, la séparation entre interface et logique facilite les évolutions suivantes.

Cette version est donc une amélioration de confort (moins de ressaisie) et aussi une amélioration technique (code plus propre à maintenir).

Persistance des données

Le profil est enregistré en JSON pour retrouver les informations au prochain lancement

Architecture en couches

Le code est séparé en deux parties : l'interface (mobile) et la logique (mobile.Core)

Restauration automatique

Les champs sont préremplis au démarrage avec les dernières données saisies

Code amélioré

Ajout d'une classe Serializer pour gérer la sauvegarde et le chargement

Extraits de code (persistance JSON)

Enregistrement du profil au format JSON dans le dossier local de l'application :

string jsonString = JsonSerializer.Serialize(profil);
string fichier = Path.Combine(
    Environment.GetFolderPath(Environment.SpecialFolder.LocalApplicationData),
    nomFichier);
File.WriteAllText(fichier, jsonString);

Chargement du même fichier au démarrage (restauration des champs si le fichier existe) :

if (File.Exists(fichier))
{
    string jsonString = File.ReadAllText(fichier);
    profil = JsonSerializer.Deserialize<Profil>(jsonString);
}

Après un calcul réussi, le profil est sauvegardé pour la prochaine ouverture :

Profil unProfil = new Profil(sexe, poids, taille, age);
Serializer.serialize(nomFichier, unProfil);
